LOCAL VISUAL MEMORY

视觉记忆

每 3 秒本机截取前台窗口并运行 Apple Vision OCR；仅当画面内容变化时保留文字观察。Qwen3-VL 按设定间隔分析代表性画面，临时图片处理后删除。

每小时将 OCR 与视觉描述交给当前文本模型（默认 qwen3.5:4b），追加到 data/memories/日期.md；记忆保留 30 天。截图采集总开关关闭时，本功能也会暂停。
